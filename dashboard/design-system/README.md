# Sloper design system

The console's visual contract is documented in [SLOPER-GLASS.md](SLOPER-GLASS.md) and machine-readable checks live in [design-contract.json](design-contract.json).

Run the static evaluator from `dashboard/frontend`:

```bash
npm run evaluate:design
```

For the Chrome MCP review workflow, use `.agents/skills/sloper-design-review/SKILL.md`.
